# Map interaction

[Español](README.es.md)

Learning example: Map interaction, location selection and geolocation; address search needs a compatible geocoding endpoint.

Stack: Angular 20 · Ionic · Leaflet.

## Centralized example

The source is preserved in this repository. The runnable collection copy, with its own dependency lockfile, build configuration and instructions, lives in [Angular Examples](https://github.com/matigaleanodev/angular-examples/tree/main/examples/map-interaction-demo).

For local use, follow the collection README and its `.nvmrc` (install the indicated Node version if needed):

```sh
git clone https://github.com/matigaleanodev/angular-examples.git
cd angular-examples/examples/map-interaction-demo
nvm use
npm ci --ignore-scripts
npm start
```

The commands above run the centralized copy. This original repository remains a learning reference; it is not a production application template.
